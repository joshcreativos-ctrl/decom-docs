# Una imagen vale más que cien adjetivos

<Callout type="info">
El cerebro humano procesa imágenes **60,000 veces más rápido que texto** (3M Corporation Research, citado en estudios de neurociencia visual).
</Callout>

Lo mismo aplica a la IA. Si tú le escribes 500 palabras describiendo un estilo, va a captar el 30%. Si le das **UNA imagen** de referencia, capta el 80% en un segundo.

---

## Comparativa real

### ❌ Prompt solo texto (capta ~30%)

```
Hazme un flyer minimalista, sobrio, editorial, en colores neutros,
con tipografía moderna serif, mucho espacio en blanco, look 
premium estilo revista, composición asimétrica, fotografía en 
blanco y negro de alta calidad, atmósfera contemplativa pero 
no aburrida, similar a lo que harían marcas como Aēsop o COS, 
con un toque cálido pero no excesivo...
```

La IA tiene que **interpretar** cada palabra. Y cada interpretación es una oportunidad de error.

### ✅ Prompt con referente (capta ~80%)

```
Con base en este estilo visual [📎 3 imágenes adjuntas], 
genera un flyer para este evento.
```

La IA **ve** exactamente lo que quieres. No interpreta: copia el ADN visual.

---

## La regla: muestra antes de describir

| Para esto... | Mejor que describir... | Mejor mostrar... |
|---|---|---|
| Estilo visual | Lista de adjetivos | Imágenes de referencia |
| Paleta de colores | "tonos cálidos y tierra" | Una imagen con esa paleta |
| Tipografía | "serif moderno editorial" | Un poster con esa tipografía |
| Composición | "asimétrica con jerarquía" | Un layout que la tenga |
| Logo | "el logo de DECOM" | El PNG del logo |
| Persona específica | Descripción | Su foto |

---

## Las 4 cosas que SÍ debes describir (no mostrar)

A pesar de la regla, hay cosas que la imagen no puede transmitir y SÍ debes describir en texto:

<Cards>
  <Card title="Texto exacto" description="La IA no sabe qué texto poner. Lo dices letra por letra." />
  <Card title="Datos del evento" description="Fecha, hora, lugar. Imposibles de mostrar." />
  <Card title="Restricciones" description="Lo que NO quieres ('no uses fucsia', 'sin cruces')." />
  <Card title="Detalles funcionales" description="Si hay QR, si hay logo en una esquina específica." />
</Cards>

## Tip pro: combina imagen y texto

El prompt ganador siempre es:

```
[Adjuntar 3 imágenes de referencia]
+
"Con base en este estilo visual genera un flyer..."
+
[Brief con datos exactos del evento]
+
[Adjuntar logos]
```

Esa combinación es lo que produce resultados profesionales en 2-3 intentos.

---

## Cuántos referentes mostrar

- **1 imagen** → la IA copia demasiado. Riesgo de plagio visual.
- **3 imágenes** → ✅ el punto dulce. La IA entiende el "lenguaje" sin copiar.
- **5+ imágenes** → la IA se confunde. Pierde claridad.

Si la herramienta te permite adjuntar 3, adjunta 3. Ni más, ni menos.

> **Siempre que puedas, muestra. Solo describe lo que la imagen no muestra.**
