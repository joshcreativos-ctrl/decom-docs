## Plantillas oficiales

### Plantilla de brief para ChatGPT

```
Por favor, con base en este estilo visual genera un flyer para 
este evento. Es importante que uses los logos que también te 
adjunto.

Información del evento:
- Nombre del evento:
- Fecha:
- Hora:
- Lugar:
- Mood (qué deben sentir):
- Audiencia:
- Texto destacado:
- Texto secundario:
- Texto pequeño:
- Colores que NO quieres usar:
```

### Plantilla de prompt para SUNO (jingle)

```
Style of Music:
Upbeat acoustic pop, warm vocals, soft guitar, light percussion, 
inspiring, 95 BPM, modern worship style, mixed voices

Lyrics:
[Verse]
[Tu mensaje aquí, 4 líneas]

[Chorus]
[Nombre del evento, repetir 2-3 veces]

[Outro]
[Llamado a la acción breve]
```

### Plantilla de prompt para SUNO (cortina instrumental)

```
Style of Music:
Cinematic instrumental, ambient pads, soft piano, building strings, 
ethereal, 15 seconds, no vocals, modern worship underscore

Lyrics:
[Instrumental]
```

## Checklists descargables

### Checklist de verificación de flyer (los 5 puntos)

```
[ ] 1. Tipografía: ¿se entiende? ¿sin errores ortográficos?
[ ] 2. Anatomía: ¿manos con 5 dedos? ¿proporciones humanas?
[ ] 3. Consistencia: si hay varias personas o piezas, ¿coherentes?
[ ] 4. Logos: ¿completos? ¿sin deformaciones?
[ ] 5. Imagen personal: si hay personas reales, ¿se respeta la dignidad?
[ ] 6. Datos: ¿fecha, hora, lugar correctos?
[ ] 7. Mood: ¿coincide con el evento?
[ ] 8. Jerarquía: ¿se entiende qué leer primero?
```

### Checklist de verificación de jingle

```
[ ] 1. Letra: ¿se entiende cada palabra?
[ ] 2. Mood: ¿coincide con el evento?
[ ] 3. Duración: ¿encaja con el uso?
[ ] 4. Calidad: ¿sin artefactos raros?
[ ] 5. Mensaje: ¿el contenido es correcto?
```
