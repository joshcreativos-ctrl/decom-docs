# Paso 3: El prompt

Ya tienes los referentes y logos adjuntados. Ahora vas a escribir la instrucción exacta. **Las palabras importan.**

---

## La plantilla oficial DECOM

Cópiala y pégala en ChatGPT, luego rellena cada campo:

```
Por favor, con base en este estilo visual genera un flyer para 
este evento. Es importante que uses los logos que también te 
adjunto.

Información del evento:
- Nombre del evento:
- Fecha:
- Hora:
- Lugar:
- Mood (qué deben sentir):
- Audiencia:
- Texto destacado (lo más importante):
- Texto secundario:
- Texto pequeño:
- Colores que NO quieres usar:
```

<Callout type="warn">
**Llena TODOS los campos.** Lo que dejes vacío, la IA lo inventa.
</Callout>

---

## Ejemplo completo (real)

Así se ve un prompt bien llenado para un congreso de jóvenes:

```
Por favor, con base en este estilo visual genera un flyer para 
este evento. Es importante que uses los logos que también te 
adjunto.

Información del evento:
- Nombre del evento: SHIFT 2026 - Congreso de Jóvenes
- Fecha: Sábado 14 de marzo de 2026
- Hora: 6:00 PM - 10:00 PM
- Lugar: Auditorio Central IPUC, Bogotá
- Mood (qué deben sentir): Energía, expectativa, urgencia
- Audiencia: Jóvenes de 15 a 25 años
- Texto destacado: SHIFT 2026
- Texto secundario: Congreso de Jóvenes - 14 de marzo
- Texto pequeño: Entrada gratuita - Inscripciones en decom.ipuc.co
- Colores que NO quieres usar: Rosa pastel, fucsia
```

---

## Por qué cada campo importa

| Campo | Por qué importa |
|---|---|
| **Nombre del evento** | Va a ser el texto más grande de la pieza |
| **Fecha** | Si la IA la inventa, podría poner cualquier fecha |
| **Hora** | A veces se incluye, a veces no — la IA decide mejor con dato |
| **Lugar** | Para que la pieza tenga toda la info |
| **Mood** | Define la dirección creativa |
| **Audiencia** | Influye en estilo (juvenil vs sobrio) |
| **Texto destacado** | Lo que el ojo verá primero |
| **Texto secundario** | El segundo nivel de jerarquía |
| **Texto pequeño** | Los detalles que no pueden faltar |
| **Colores prohibidos** | Para evitar resultados que no quieras |

---

## Variantes útiles del prompt

### Para banner cuadrado (Instagram post):

```
Por favor, genera la versión cuadrada (1080x1080) de este flyer 
manteniendo el mismo estilo visual...
```

### Para story vertical:

```
Por favor, genera la versión vertical 9:16 (1080x1920) para 
historias de Instagram, manteniendo el mismo estilo y jerarquía...
```

### Para banner horizontal (YouTube, web):

```
Por favor, genera la versión horizontal 16:9 (1920x1080) para 
banner, manteniendo el mismo estilo visual...
```

---

## Reglas no negociables del prompt

<Callout type="info">
1. **Adjunta primero, escribe después.** Que la IA vea los referentes antes de leer.
2. **Pide UN flyer por mensaje.** No "hazme 3 versiones distintas" en el mismo prompt.
3. **Si quieres variaciones, pídelas después.** Genera primero el principal, luego pide variantes.
4. **Especifica el formato** (vertical, horizontal, cuadrado) si no es obvio.
5. **Menciona los logos explícitamente:** "es importante que uses los logos adjuntos sin modificarlos".
</Callout>

---

## Frases mágicas para mejorar resultados

Añade al final del prompt según necesites:

| Si quieres... | Añade esta frase |
|---|---|
| Mejor calidad fotográfica | "shot on medium format camera, editorial quality" |
| Tipografía limpia | "clean modern typography, professional layout" |
| Más impacto | "bold composition, strong hierarchy" |
| Look minimalista | "minimalist design, generous white space" |
| Look cinematográfico | "cinematic lighting, dramatic atmosphere" |
